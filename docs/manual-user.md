# 使用手册（QQ 用户）

这份手册面向在 QQ 里和机器人聊天的人。你不需要登录服务器，也不需要懂 DSH。

## 1. 它能做什么

机器人把 QQ 当成 DSH 工作区的远程入口：

- 私聊机器人，等于和某个工作区里的 AI 助手对话；
- 每个 QQ 用户有自己的工作区目录，互相隔离；
- 群里 @机器人 也能用，但整个群共用一个工作区和一个会话；
- 可以让它读文件、改文件、跑命令，具体能力取决于你的权限等级。

## 2. 第一次使用

1. 加机器人 QQ 为好友（本机部署实例是 `123456789`，以实际为准）；
2. 私聊发送：

```
/whoami
```

会返回你的 QQ 号、等级、当前工作区、当前会话和排队数。

3. 如果等级是 `L0`，你只能只读对话。找管理员要一个配对码，然后发：

```
/bind 123456
```

绑定成功会返回新的等级（通常是 `L1`）。

## 3. 普通对话

- 直接发文字就是对话，会进入你当前的工作区会话；
- 以 `/` 开头的会被当成指令，不会发给模型；
- 回复太长时会自动分成多条；
- 同一个人连续发消息会排队，一次只跑一轮；
- 单轮超过 5 分钟会提示超时并中断。

## 4. 指令速查

| 指令 | 作用 |
|---|---|
| `/help` | 显示可用指令 |
| `/whoami` | 我的等级、工作区、会话 |
| `/status` | 连接和队列状态 |
| `/bind <配对码>` | 绑定账号 |
| `/ws list` | 我的工作区列表 |
| `/ws new <名称>` | 新建工作区并切过去 |
| `/ws use <序号\|名称>` | 切换工作区 |
| `/ws info` | 当前工作区详情 |
| `/ws rename <名称>` | 重命名当前工作区（目录不变） |
| `/new` | 在当前工作区新开一个会话 |
| `/reset` | 重置为新会话（等同 `/new`） |
| `/sessions` | 当前工作区的会话列表 |
| `/use <序号>` | 切换到某个会话 |
| `/stop` | 中断当前这一轮 |

## 5. 工作区是什么

工作区就是服务器上的一个目录，默认在：

```
E:\QQdsh\u-<你的编号>\<工作区名>\
```

你在 QQ 里让它“看看这个目录”“把结果写到文件里”，实际操作的就是这里。不同工作区之间上下文和文件是分开的。

- 默认会有一个 `default` 工作区；
- `/ws new` 可以再建，数量受等级配额限制；
- 切换工作区后，下一条普通消息进入新工作区的会话。

## 6. 群里怎么用

- 必须 **@机器人** 才会响应，不 @ 的消息会被忽略；
- 整个群共用一个工作区和一个会话，上下文是连续的；
- 回复会自动 @ 你；
- 群里只能用 `/ws info`；`/new`、`/reset` 只有管理员能用；
- 未绑定（L0）时在群里发普通消息会提示先 `/bind`。

注意：群工作区的文件和会话内容是群内共享的，不要把私密内容发到群里。

## 7. 权限等级

| 等级 | 能做什么 |
|---|---|
| L0 访客 | 只读对话，落在共享访客工作区；不能建工作区 |
| L1 用户 | 自己的默认工作区，可新建/切换，默认最多 3 个 |
| L2 高级 | 更高配额（默认 10 个工作区） |
| L3 管理员 | 不限工作区，可管理用户和所有工作区 |

等级由管理员调整；配额用完后当天不能再发对话，但指令仍可用。

## 8. 审批

当某个操作需要你确认时，机器人会发：

```
【审批】工具 bash
原因：...
回复 1 允许，2 拒绝（120 秒）
```

- 只有发起这一轮的人能回答；
- 回复 `1`/`允许` 通过，`2`/`拒绝` 拒绝；
- 超时默认拒绝；
- 访客（L0）的审批请求会被直接拒绝，不会弹提示。

## 9. 常见问题

**机器人不回复**
- 私聊里是不是发了 `/` 开头的未知指令？先 `/help`；
- 群里是不是忘了 @；
- 配额是否用完（`/status` 看不了配额，直接发消息会有提示）；
- 机器人或 NapCat 掉线，找管理员。

**提示权限不足**
- 该指令需要更高等级，先 `/bind` 或找管理员。

**配对码无效**
- 配对码一次性、默认 5 分钟过期，找管理员重新生成。

**回复“处理失败”**
- 通常是模型服务或凭据问题，把报错原文发给管理员。

**图片**
- 当前版本不处理图片，图片会变成 `[图片]` 文字；不要指望它能看懂图。

**会话恢复失败后像失忆了**
- 插件会回退新建会话；历史仍在磁盘上，可用 `/sessions` 和 `/use` 切回旧会话。
